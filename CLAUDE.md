# CLAUDE.md

Тест «Безкоштовна діагностика рівня» для сайту шахової школи yaroslavchess.com.
Аудиторія: українські батьки за кордоном із дітьми 6–14 років і дорослі; більшість батьків
не грає в шахи. Публікація — GitHub Pages з кореня репозиторію. Дивіться також `README.md`.

## Правила проєкту (не порушувати)

**Файли й код**
- Тест — **один файл `index.html`** (HTML, CSS і скрипт разом). Зовнішні залежності лише
  одна: шахова бібліотека з CDN (див. нижче).
- Власний JavaScript — класичний ES5: `var`, `function`, без стрілкових функцій
  (`=>`), без `let`/`const`, шаблонних рядків і класів. Це стосується лише коду, який
  пишемо ми; підключена бібліотека може бути будь-якою.
- Інтерфейс повністю українською. Адаптивний під телефон (перевіряти на ширині 375 px,
  без горизонтального скролу, клітинки дошки не менші за ~40 px).

**Задачі**
- Лише з відкритої бази Lichess (<https://database.lichess.org>, CC0), рейтинг приблизно
  від 500 до 2000. **Задачі не вигадувати й не редагувати вручну.** Оновлювати набір тільки
  через `tools/pick_puzzles.py` з реального файлу бази.
- У коді зберігати для кожної задачі: `id` (ID Lichess), `rating`, `fen` (до першого ходу
  суперника) і `moves` (правильна послідовність, перший хід — суперника).
- Після будь-якої зміни задач перевірити, що всі FEN коректні й усі ходи легальні
  (завантажити кожну через chess.js і зіграти `moves`).

**Логіка тесту**
- 12 задач. Правильна відповідь → наступна задача складніша, помилка → простіша
  (кроки в `STEPS`). Одна спроба на задачу, без підказок; правильність не показується
  користувачу («Відповідь прийнято»).
- Задача зарахована, лише якщо зіграно **всю** правильну послідовність; будь-який хід, що
  ставить мат, теж правильний.
- Ходи — тільки натисканням на клітинки (вибір фігури, потім цілі). Без перетягування.
- Старт: екран вибору «Дитина / Дорослий» і кнопка «Почати»; окрема кнопка «Ще не граю»
  одразу дає результат «Новачок».
- Рівні рівно такі: Новачок / Початківець / Середній / Впевнений / Сильний, пороги —
  0 / 700 / 1000 / 1300 / 1650 (змінюються лише на прохання власника).
- Результат: рівень, пояснення рівно з двох речень **без шахових термінів**, кнопка
  «Записатися на безкоштовний пробний урок» із посиланням `BOOKING_URL`.

**Бібліотека правил**
- Не писати власний рушій правил. Використовується chess.js **0.10.3** з jsDelivr із
  фіксованою версією та `integrity` (SRI). Версії 1.x не підходять: це ES-модулі.
  Якщо змінюєте версію, перерахуйте SRI з файлу пакета npm і перевірте, що сторінка
  працює.

**Приватність**
- Сторінка не збирає й не зберігає жодних персональних даних: без форм, cookie,
  `localStorage`/`sessionStorage`/IndexedDB, аналітики, пікселів, шрифтів із зовнішніх
  сайтів. Єдиний зовнішній запит — chess.js. Посилання на запис — звичайний `<a>` без
  параметрів, що ідентифікують користувача.

**Дизайн**
- Палітра: темно-синій `#1a2c54`, червоно-оранжевий `#d6401a` (кнопки; білий текст на ньому
  має контраст ≥ 4.5:1), світло-блакитний `#e8f2fc` / `#cfe5f8`.

## Перед завершенням зміни

1. Проходження тесту в браузері (Playwright, вікно 375 px, мобільний режим): усі відповіді
   правильні → «Сильний»; усі помилкові → «Новачок»; змішаний сценарій; «Ще не граю».
2. Немає помилок у консолі, `localStorage`/`sessionStorage`/cookie порожні, зовнішній
   запит один (chess.js).
3. `grep -n "=>" index.html` нічого не знаходить.
4. `BOOKING_URL` заповнений реальним посиланням (власник має вставити своє; не вигадувати).
5. Гілка розробки: `claude/chess-level-test-mgyk5h`. PR відкривати лише на прохання
   власника.

## Міні-шахи (`mini-chess/`)

Окрема гра для дітей 4–7 років на дошці 5×5 (`mini-chess/index.html`, див.
`mini-chess/README.md`). Правила вище діють і тут (один файл, ES5, українська, 375 px,
палітра), крім винятків, погоджених власником:
- прогрес (зірочки, «усі рівні відкрито», вимкнений звук) зберігається в `localStorage`
  під ключем `mini-chess-progress-v1` — і більше нічого;
- онлайн-гра з вчителем через Ably (2.29.0, jsDelivr + SRI), бібліотека вантажиться лише
  в онлайн-режимі; `ABLY_KEY` вставляє власник;
- правила 5×5 рахує власний рушій між `ENGINE:START` і `ENGINE:END` (chess.js не вміє 5×5).
  Після зміни рушія: `node --test mini-chess/tests/engine.test.js` і
  `node mini-chess/tests/e2e.js`.
