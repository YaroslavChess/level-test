# CLAUDE.md

Тест «Безкоштовна діагностика рівня» для сайту шахової школи yaroslavchess.com.
Аудиторія: українські батьки за кордоном із дітьми 6–14 років і дорослі; більшість батьків
не грає в шахи. Публікація — GitHub Pages з кореня репозиторію. Дивіться також `README.md`.

## Що робить проєкт

Статична сторінка: 12 адаптивних шахових задач «знайди найкращий хід» (з відкритої бази
Lichess), після них — один із п'яти рівнів, пояснення з двох речень і кнопка запису на
безкоштовний пробний урок (`BOOKING_URL`, зараз `https://www.yaroslavchess.com/appointment`).
Бекенду, збирання й залежностей від npm немає.

## Структура файлів

```
index.html              увесь тест: HTML + CSS + скрипт (один файл)
tools/pick_puzzles.py   відбір задач з бази Lichess → JS-масив PUZZLES
README.md               короткий опис для людини
CLAUDE.md               цей файл
```

Усередині `index.html`:
- блок «НАЛАШТУВАННЯ» на початку скрипта: `BOOKING_URL`, `TOTAL_TASKS`, `START_RATING`,
  `STEPS`, `LEVELS`, `RESULT_TEXTS`;
- масив `PUZZLES` між маркерами `/* PUZZLES:START */` і `/* PUZZLES:END */` (зараз 93
  задачі);
- `computeLevelIndex()` — підрахунок рівня за оцінкою.

## Як запускається

Збирати нічого не треба. Локально: відкрити `index.html` у браузері або
`python3 -m http.server 8000` у корені й перейти на `http://localhost:8000/`. Потрібен
доступ до `cdn.jsdelivr.net` (chess.js). Публікація: GitHub Pages, гілка `main`, папка
`/ (root)` → `https://yaroslavchess.github.io/level-test/`.

## Секрети

Не потрібні жодні: ні змінних середовища, ні ключів, ні токенів. `BOOKING_URL` — публічне
посилання, не секрет. Не додавати в репозиторій жодних ключів чи персональних даних.

## Правила проєкту (не порушувати)

**Файли й код**
- Тест — **один файл `index.html`** (HTML, CSS і скрипт разом). Зовнішні залежності лише
  одна: шахова бібліотека з CDN (див. нижче).
- Власний JavaScript — класичний ES5: `var`, `function`, без стрілкових функцій
  (`=>`), без `let`/`const`, шаблонних рядків і класів. Це стосується лише коду, який
  пишемо ми; підключена бібліотека може бути будь-якою.
- Інтерфейс повністю українською. Адаптивний під телефон (перевіряти на ширині 375 px,
  без горизонтального скролу, клітинки дошки не менші за ~40 px).

**Задачі**
- Лише з відкритої бази Lichess (<https://database.lichess.org>, CC0), рейтинг приблизно
  від 500 до 2000. **Задачі не вигадувати й не редагувати вручну.** Оновлювати набір тільки
  через `tools/pick_puzzles.py` з реального файлу бази.
- У коді зберігати для кожної задачі: `id` (ID Lichess), `rating`, `fen` (до першого ходу
  суперника) і `moves` (правильна послідовність, перший хід — суперника).
- Після будь-якої зміни задач перевірити, що всі FEN коректні й усі ходи легальні
  (завантажити кожну через chess.js і зіграти `moves`; готовий скрипт — нижче).

**Логіка тесту**
- 12 задач. Правильна відповідь → наступна задача складніша, помилка → простіша
  (кроки в `STEPS`). Одна спроба на задачу, без підказок; правильність не показується
  користувачу («Відповідь прийнято»).
- Задача зарахована, лише якщо зіграно **всю** правильну послідовність; будь-який хід, що
  ставить мат, теж правильний.
- Ходи — тільки натисканням на клітинки (вибір фігури, потім цілі). Без перетягування.
- Старт: екран вибору «Дитина / Дорослий» і кнопка «Почати»; окрема кнопка «Ще не граю»
  одразу дає результат «Новачок».
- Рівні рівно такі: Новачок / Початківець / Середній / Впевнений / Сильний, пороги —
  0 / 700 / 1000 / 1300 / 1650 (змінюються лише на прохання власника).
- Результат: рівень, пояснення рівно з двох речень **без шахових термінів**, кнопка
  «Записатися на безкоштовний пробний урок» із посиланням `BOOKING_URL`.

**Бібліотека правил**
- Не писати власний рушій правил. Використовується chess.js **0.10.3** з jsDelivr із
  фіксованою версією та `integrity` (SRI). Версії 1.x не підходять: це ES-модулі.
  Якщо змінюєте версію, перерахуйте SRI з файлу пакета npm і перевірте, що сторінка
  працює.

**Приватність**
- Сторінка не збирає й не зберігає жодних персональних даних: без форм, cookie,
  `localStorage`/`sessionStorage`/IndexedDB, аналітики, пікселів, шрифтів із зовнішніх
  сайтів. Єдиний зовнішній запит — chess.js. Посилання на запис — звичайний `<a>` без
  параметрів, що ідентифікують користувача.

**Дизайн**
- Палітра: темно-синій `#1a2c54`, червоно-оранжевий `#d6401a` (кнопки; білий текст на ньому
  має контраст ≥ 4.5:1), світло-блакитний `#e8f2fc` / `#cfe5f8`.

## Як перевірити зміни

Перед завершенням будь-якої зміни:

1. **Проходження в браузері** (Playwright, вікно 375 px, мобільний режим): усі відповіді
   правильні → «Сильний»; усі помилкові → «Новачок»; змішаний сценарій; «Ще не граю».
2. **Консоль і сховище:** немає помилок у консолі; `localStorage`/`sessionStorage`/cookie
   порожні; зовнішній запит один (chess.js).
3. **ES5:** `grep -n "=>" index.html` нічого не знаходить.
4. **Задачі** (якщо їх чіпали): усі FEN коректні, усі ходи легальні — скрипт нижче.
5. **`BOOKING_URL`** заповнений реальним посиланням (власник вставляє своє; не вигадувати).
6. **SRI** (якщо чіпали версію chess.js): `openssl dgst -sha384 -binary chess.js | openssl
   base64 -A` для файлу з npm-пакета (`npm pack chess.js@0.10.3`), додати префікс `sha384-`.

Перевірка задач (Node; `package/chess.js` — з `npm pack chess.js@0.10.3`, розпакованого
`tar xzf`; зберегти як `check.js` поза репозиторієм і запустити `node check.js`):

```js
var fs = require('fs');
var Chess = require('./package/chess.js').Chess;
var html = fs.readFileSync('index.html', 'utf8');
var a = html.indexOf('/* PUZZLES:START */'), b = html.indexOf('/* PUZZLES:END */');
var PUZZLES = new Function(html.slice(a, b) + '; return PUZZLES;')();
var bad = 0;
PUZZLES.forEach(function (p) {
  var g = new Chess();
  if (!g.load(p.fen)) { console.log('Поганий FEN', p.id); bad++; return; }
  p.moves.split(' ').forEach(function (m) {
    var r = g.move({ from: m.slice(0, 2), to: m.slice(2, 4), promotion: m[4] });
    if (!r) { console.log('Нелегальний хід', p.id, m); bad++; }
  });
});
console.log('Задач: ' + PUZZLES.length + ', помилок: ' + bad);
process.exit(bad ? 1 : 0);
```

(Станом на зараз: 93 задачі, 0 помилок; SRI у `index.html` збігається з пакетом 0.10.3.)
