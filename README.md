# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
задач «знайди найкращий хід» на інтерактивній дошці, потім результат (один із п'яти рівнів)
і кнопка запису на безкоштовний пробний урок. Для українських батьків за кордоном (діти
6–14 років) і дорослих. Більшість батьків не грає, тому текст результату написано без
шахових термінів.

Увесь тест — **один файл `index.html`**. Збирати нічого не потрібно.

## Як це працює

- Стартовий екран: хто проходить (дитина / дорослий), кнопка «Почати». Кнопка «Ще не граю»
  одразу показує результат «Новачок».
- 12 задач із відкритої бази Lichess. Одна спроба на задачу, без підказок. Задача
  вважається розв'язаною, лише якщо правильно зіграно **всю** послідовність ходів із бази
  (будь-який хід, що одразу ставить мат, теж зараховується, як на Lichess).
- Адаптивність: правильна відповідь — наступна задача складніша, помилка — простіша.
  Крок складності зменшується з 300 до 100 пунктів рейтингу.
- Ходи на телефоні — натисканням: спершу на фігуру, потім на клітинку. Перетягування немає.
- Результат: рівень, пояснення з двох речень і кнопка запису.

## Публікація через GitHub Pages

1. Тест у `main` (зміни вносьте через гілку й PR).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)`.
3. Сторінка з'явиться за адресою `https://yaroslavchess.github.io/level-test/`. Її можна
   вставити на сайт через `<iframe>` або дати як посилання.

## Посилання на запис

Відкрийте `index.html` і знайдіть блок «НАЛАШТУВАННЯ» на початку скрипта:

```js
var BOOKING_URL = 'https://www.yaroslavchess.com/appointment';
```

Зараз кнопка веде на сторінку запису сайту. Щоб змінити посилання, замініть рядок у лапках.
Якщо рядок порожній, кнопка веде в нікуди (`#`), тож публікувати з порожнім значенням не можна.

## Як змінити назви рівнів і пороги

У тому самому блоці «НАЛАШТУВАННЯ»:

```js
var LEVELS = [
  { name: 'Новачок', min: 0 },
  { name: 'Початківець', min: 700 },
  { name: 'Середній', min: 1000 },
  { name: 'Впевнений', min: 1300 },
  { name: 'Сильний', min: 1650 }
];
```

- `name` — назва рівня, яку бачить користувач.
- `min` — мінімальна оцінка (за шкалою рейтингу задач), з якої починається рівень.
  Оцінка — це середнє з рейтингів останніх чотирьох задач і наступної цільової складності.
  Якщо жодної задачі не розв'язано, результат завжди «Новачок».
- Рівнів має бути п'ять, у порядку від найслабшого до найсильнішого. Якщо змінюєте кількість,
  змініть і кількість текстів у `RESULT_TEXTS`.

Пояснення результату — об'єкт `RESULT_TEXTS` (окремо для `child` і `adult`, по одному тексту
на рівень, у тому самому порядку, що й `LEVELS`). Пишіть рівно два речення й без шахових
термінів. Стартова складність: `START_RATING` (дитина 900, дорослий 1200); кількість задач:
`TOTAL_TASKS`; кроки зміни складності: `STEPS`.

## Як змінити задачі

Задачі лежать у масиві `PUZZLES` між рядками `/* PUZZLES:START */` і `/* PUZZLES:END */` в
`index.html`. Кожна задача — це запис із відкритої бази Lichess (ліцензія CC0), без змін:

```js
{ id: "ppRON", rating: 488, fen: "…позиція ДО першого ходу суперника…",
  moves: "h1f2 g4g7" },
```

- `id` — ідентифікатор задачі (її можна відкрити на `https://lichess.org/training/<id>`);
- `rating` — рейтинг задачі;
- `fen` — позиція до першого ходу суперника;
- `moves` — правильна послідовність ходів у форматі UCI: перший хід робить суперник, далі
  по черзі розв'язувач і суперник.

**Задачі не вигадуйте й не правте вручну** — тільки беріть із бази Lichess. Щоб оновити
набір:

1. Завантажте базу: <https://database.lichess.org/lichess_db_puzzle.csv.zst> (близько 300 МБ).
2. Встановіть `pip install zstandard` (потрібно лише для `.zst`).
3. Запустіть відбір (використано 3 задачі на кожні 50 пунктів рейтингу від 500 до 2000,
   тільки популярні задачі з короткою послідовністю):

   ```
   python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js
   ```

4. Замініть вміст між `PUZZLES:START` і `PUZZLES:END` на вміст `puzzles.js`.

У банку має бути щонайменше 12 задач (краще 60 і більше; зараз 93).

Критерії відбору — у верхній частині `tools/pick_puzzles.py`. Для адаптивності потрібно
кілька задач на кожен діапазон рейтингу, особливо біля 500 і 2000: інакше після кількох
правильних відповідей запас складних задач закінчиться.

## Приватність

Сторінка не збирає й не зберігає жодних персональних даних: немає форм, cookie,
`localStorage`, аналітики. Результат існує лише в пам'яті сторінки й зникає при її
закритті. Єдиний зовнішній запит — завантаження шахової бібліотеки chess.js з CDN
jsDelivr (як і будь-який CDN, він бачить IP-адресу відвідувача; сторінка з цього нічого
не зберігає). Перехід за посиланням на запис відкриває сторінку запису на сайті
yaroslavchess.com, яка працює за власними правилами.

## Технічні подробиці

- Шахові правила (допустимі ходи, мат, перетворення пішака) обробляє перевірена бібліотека
  [chess.js](https://github.com/jhlywa/chess.js) 0.10.3 (BSD-2-Clause), підключена з
  `cdn.jsdelivr.net` із фіксованою версією й перевіркою цілісності (SRI). Версія 0.10.3
  підходить свідомо: новіші версії — ES-модулі, які не працюють у звичайному `<script>`.
- Власний код — класичний JavaScript (ES5), без стрілкових функцій.
- Задачі: відкрита база Lichess, <https://database.lichess.org>, ліцензія CC0.
- Палітра: темно-синій `#1a2c54`, червоно-оранжевий `#d6401a`, світло-блакитний
  `#e8f2fc` / `#cfe5f8`.
