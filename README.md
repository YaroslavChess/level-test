# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
шахових задач на інтерактивній дошці, потім результат (один із п'яти рівнів) і кнопка запису
на безкоштовний пробний урок. Для українських батьків за кордоном (діти 6–14 років) і
дорослих. Текст результату без шахових термінів — він зрозумілий і тим, хто не грає.

Увесь тест — **один файл `index.html`**. Збирати нічого не потрібно.

## Як це працює

- Стартовий екран: «Дитина» / «Дорослий» і кнопка «Почати». Кнопка «Ще не граю» одразу
  дає результат «Новачок».
- 12 задач із відкритої бази Lichess (CC0). Одна спроба на задачу, без підказок; ходи — лише
  натисканням (фігура, потім клітинка). Задача зарахована, якщо зіграно всю правильну
  послідовність.
- Правильна відповідь → наступна задача складніша, помилка → простіша.
- Рівні: Новачок / Початківець / Середній / Впевнений / Сильний.
- Сторінка нічого не збирає й не зберігає: без форм, cookie, `localStorage` і аналітики.
  Єдиний зовнішній запит — шахова бібліотека chess.js з CDN jsDelivr.

## Публікація (GitHub Pages)

Settings → Pages → *Deploy from a branch* → `main`, `/ (root)`. Сторінка буде за адресою
`https://yaroslavchess.github.io/level-test/`; її можна вставити на сайт через `<iframe>` або
дати посиланням.

## Що можна налаштувати

Усе — у блоці «НАЛАШТУВАННЯ» на початку скрипта в `index.html`:

- `BOOKING_URL` — посилання кнопки запису (зараз `https://www.yaroslavchess.com/appointment`);
- `LEVELS` — назви рівнів і пороги (0 / 700 / 1000 / 1300 / 1650);
- `RESULT_TEXTS` — тексти результату (рівно два речення, без шахових термінів);
- `START_RATING`, `TOTAL_TASKS`, `STEPS` — стартова складність, кількість задач, крок зміни.

## Як оновити задачі

Задачі не вигадуємо й не правимо вручну — лише з бази Lichess:

1. Завантажте <https://database.lichess.org/lichess_db_puzzle.csv.zst> (~300 МБ) і виконайте
   `pip install zstandard`.
2. `python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js` (по 3 задачі на
   кожні 50 пунктів рейтингу від 500 до 2000; зараз у тесті 93 задачі).
3. Замініть вміст між `/* PUZZLES:START */` і `/* PUZZLES:END */` в `index.html` на вміст
   `puzzles.js` і перевірте, що всі ходи легальні.

## Для розробників

Правила проєкту та перелік перевірок — у [CLAUDE.md](CLAUDE.md). Коротко: власний код на
ES5 (без `=>`, `let`, `const`), правила шахів — тільки chess.js 0.10.3 із SRI, палітра
`#1a2c54` / `#d6401a` / `#e8f2fc` / `#cfe5f8`.
