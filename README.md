# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
шахових задач «знайди найкращий хід», потім результат (один із п'яти рівнів) і кнопка запису
на безкоштовний пробний урок. Для українських батьків за кордоном (діти 6–14 років) і
дорослих; текст результату без шахових термінів.

Увесь тест — **один файл `index.html`**, збирати нічого не потрібно.

## Як це працює

- Старт: «Дитина / Дорослий» і «Почати». Кнопка «Ще не граю» одразу дає результат «Новачок».
- 12 задач із відкритої бази Lichess (CC0). Одна спроба, без підказок. Задача зарахована,
  лише якщо зіграно всю правильну послідовність.
- Правильна відповідь — наступна задача складніша, помилка — простіша.
- Ходи — натисканням: спершу фігура, потім клітинка (без перетягування).
- Рівні: Новачок / Початківець / Середній / Впевнений / Сильний. Результат — рівень, два
  речення пояснення й кнопка запису.

## Запуск і публікація

Локально: `python3 -m http.server 8000` у корені, далі <http://localhost:8000/> (потрібен
інтернет для chess.js).

GitHub Pages: Settings → Pages → *Deploy from a branch* → `main`, `/ (root)`. Адреса:
`https://yaroslavchess.github.io/level-test/`; сторінку можна вставити на сайт через
`<iframe>` або дати як посилання.

## Що можна змінити

Усе в блоці «НАЛАШТУВАННЯ» на початку скрипта в `index.html`:

- `BOOKING_URL` — посилання кнопки запису (зараз `https://www.yaroslavchess.com/appointment`);
- `LEVELS` — назви рівнів і пороги (`min`), `RESULT_TEXTS` — пояснення (рівно два речення,
  без шахових термінів, текстів стільки ж, скільки рівнів);
- `START_RATING`, `TOTAL_TASKS`, `STEPS` — стартова складність, кількість задач, кроки зміни
  складності.

## Задачі

Масив `PUZZLES` між `/* PUZZLES:START */` і `/* PUZZLES:END */` (зараз 93 задачі) взято з бази
Lichess без змін. **Не вигадуйте й не правте їх вручну**, оновлюйте лише скриптом:

```
# база: https://database.lichess.org/lichess_db_puzzle.csv.zst; для .zst: pip install zstandard
python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js
```

Далі замініть вміст між `PUZZLES:START` і `PUZZLES:END` на вміст `puzzles.js`. Критерії відбору
— на початку `tools/pick_puzzles.py`. Задач має бути щонайменше 12, а для адаптивності —
кілька на кожен діапазон рейтингу (500–2000).

## Приватність

Сторінка не збирає й не зберігає нічого: без форм, cookie, `localStorage` та аналітики.
Єдиний зовнішній запит — бібліотека [chess.js](https://github.com/jhlywa/chess.js) 0.10.3
(BSD-2-Clause) з jsDelivr, із фіксованою версією та перевіркою цілісності (SRI). Версія 0.10.3
обрана свідомо: новіші є ES-модулями. Посилання на запис — звичайне, без параметрів.

Правила для Claude Code та перевірки змін — у `CLAUDE.md`.
