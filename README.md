# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
задач «знайди найкращий хід» на інтерактивній дошці, потім результат (один із п'яти рівнів:
Новачок, Початківець, Середній, Впевнений, Сильний) і кнопка запису на безкоштовний пробний
урок. Для українських батьків за кордоном (діти 6–14 років) і дорослих; текст результату
написано без шахових термінів.

Увесь тест — **один файл `index.html`**. Збирати нічого не потрібно.

## Як це працює

- Старт: «Дитина» або «Дорослий» і «Почати». Кнопка «Ще не граю» одразу дає «Новачок».
- Одна спроба на задачу, без підказок. Задача зарахована, лише якщо зіграно всю
  правильну послідовність ходів.
- Правильна відповідь робить наступну задачу складнішою, помилка — простішою.
- Ходи на телефоні — натисканням: спершу фігура, потім клітинка.

## Запуск і публікація

Локально: відкрийте `index.html` у браузері (потрібен інтернет для шахової бібліотеки).

Публікація: GitHub Pages → Source: *Deploy from a branch* → `main`, `/ (root)`. Адреса:
`https://yaroslavchess.github.io/level-test/`. Сторінку можна вставити на сайт через
`<iframe>` або дати як посилання.

## Що можна налаштувати

Усе в блоці «НАЛАШТУВАННЯ» на початку скрипта в `index.html`:

- `BOOKING_URL` — посилання кнопки запису (зараз `https://www.yaroslavchess.com/appointment`);
- `LEVELS` — назви рівнів і пороги (0 / 700 / 1000 / 1300 / 1650);
- `RESULT_TEXTS` — пояснення результату, рівно два речення без шахових термінів, окремо для
  дитини й дорослого;
- `START_RATING`, `TOTAL_TASKS`, `STEPS` — стартова складність, кількість задач і крок
  зміни складності (від 300 до 100 пунктів).

## Як оновити задачі

Задачі — це записи відкритої бази Lichess ([CC0](https://database.lichess.org)), їх не
вигадують і не правлять вручну.

1. Завантажте <https://database.lichess.org/lichess_db_puzzle.csv.zst> (близько 300 МБ) і
   встановіть `pip install zstandard`.
2. `python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js`
3. Замініть вміст між `/* PUZZLES:START */` і `/* PUZZLES:END */` в `index.html` на
   вміст `puzzles.js`. Критерії відбору — на початку `tools/pick_puzzles.py`.

## Приватність і технічне

Сторінка нічого не збирає й не зберігає: без форм, cookie, `localStorage` і аналітики.
Єдиний зовнішній запит — бібліотека [chess.js](https://github.com/jhlywa/chess.js) 0.10.3 з
jsDelivr (фіксована версія, перевірка цілісності SRI). Власний код — класичний ES5, без
стрілкових функцій.

Правила для тих, хто змінює проєкт (зокрема для Claude Code), — у `CLAUDE.md`.
