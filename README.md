# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
шахових задач на інтерактивній дошці, після них — рівень (Новачок / Початківець / Середній /
Впевнений / Сильний) і кнопка запису на безкоштовний пробний урок. Для українських батьків за
кордоном (діти 6–14 років) і дорослих. Текст результату без шахових термінів.

Увесь тест — **один файл `index.html`**. Збирати нічого не потрібно.

## Як це працює

- Старт: «Дитина / Дорослий» і «Почати». Кнопка «Ще не граю» одразу дає результат «Новачок».
- 12 задач із відкритої бази Lichess. Одна спроба, без підказок. Задача зарахована, лише
  якщо зіграно всю правильну послідовність (хід, що ставить мат, теж підходить).
- Правильна відповідь → наступна задача складніша, помилка → простіша.
- Ходи — натисканням: спершу фігура, потім клітинка. Перетягування немає.

## Запуск і публікація

Локально (потрібен інтернет для chess.js):

```
python3 -m http.server 8000     # → http://localhost:8000/
```

GitHub Pages: Settings → Pages → *Deploy from a branch* → `main`, папка `/ (root)`.
Адреса: `https://yaroslavchess.github.io/level-test/` (можна вставити на сайт через `<iframe>`).

## Що можна налаштувати

Блок «НАЛАШТУВАННЯ» на початку скрипта в `index.html`:

- `BOOKING_URL` — посилання кнопки запису (зараз `https://www.yaroslavchess.com/appointment`);
- `LEVELS` — назви рівнів і пороги (0 / 700 / 1000 / 1300 / 1650);
- `RESULT_TEXTS` — пояснення результату: рівно два речення, без шахових термінів;
- `TOTAL_TASKS`, `START_RATING`, `STEPS` — кількість задач, стартова складність і кроки.

## Як оновити задачі

Задачі не вигадуємо й не правимо вручну — лише з [бази Lichess](https://database.lichess.org)
(CC0) через `tools/pick_puzzles.py`:

```
pip install zstandard     # лише для .zst
python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js
```

Вміст `puzzles.js` вставте в `index.html` між `/* PUZZLES:START */` і `/* PUZZLES:END */`.
Потім перевірте, що всі FEN коректні й усі ходи легальні. Базу беріть тут:
<https://database.lichess.org/lichess_db_puzzle.csv.zst> (близько 300 МБ).

## Приватність

Сторінка не збирає й не зберігає жодних даних: немає форм, cookie, `localStorage`, аналітики.
Результат існує лише в пам'яті сторінки. Єдиний зовнішній запит — шахова бібліотека
[chess.js](https://github.com/jhlywa/chess.js) 0.10.3 із CDN jsDelivr (з перевіркою цілісності
SRI). Версія 0.10.3 вибрана свідомо: новіші — ES-модулі.
