# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
шахових задач на інтерактивній дошці, потім результат (один із п'яти рівнів: Новачок,
Початківець, Середній, Впевнений, Сильний) і кнопка запису на безкоштовний пробний урок.
Для українських батьків за кордоном (діти 6–14 років) і дорослих; текст результату без
шахових термінів.

Увесь тест — **один файл `index.html`**. Збирати нічого не потрібно.

## Як це працює

- Старт: вибір «Дитина / Дорослий» і «Почати». Кнопка «Ще не граю» одразу дає «Новачок».
- Одна спроба на задачу, без підказок; правильність відповіді не показується.
- Правильна відповідь — наступна задача складніша, помилка — простіша.
- Ходи — натисканням: спершу на фігуру, потім на клітинку.
- Задачі — з відкритої бази [Lichess](https://database.lichess.org) (CC0), без змін.

## Публікація

GitHub Pages: Settings → Pages → *Deploy from a branch* → `main`, `/ (root)`. Тест буде за
адресою `https://yaroslavchess.github.io/level-test/`; його можна дати посиланням або
вставити на сайт через `<iframe>`.

## Що можна налаштувати

Усе в блоці «НАЛАШТУВАННЯ» на початку скрипта в `index.html`:

- `BOOKING_URL` — посилання кнопки запису (зараз `https://www.yaroslavchess.com/appointment`);
- `LEVELS` — назви рівнів і пороги (0 / 700 / 1000 / 1300 / 1650);
- `RESULT_TEXTS` — пояснення результату: рівно два речення без шахових термінів, окремо для
  дитини й дорослого, у порядку рівнів;
- `START_RATING`, `TOTAL_TASKS`, `STEPS` — стартова складність, кількість задач, крок зміни.

## Як оновити задачі

Задачі не вигадуємо й не правимо вручну — тільки з бази Lichess:

1. Завантажити <https://database.lichess.org/lichess_db_puzzle.csv.zst> (≈300 МБ);
   для `.zst` потрібен `pip install zstandard`.
2. `python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js`
3. Замінити вміст між `/* PUZZLES:START */` і `/* PUZZLES:END */` в `index.html`
   на вміст `puzzles.js`.

Критерії відбору — на початку `tools/pick_puzzles.py`. Після оновлення перевірте, що всі
позиції коректні й усі ходи легальні (див. `CLAUDE.md`).

## Приватність

Жодних персональних даних: без форм, cookie, `localStorage` й аналітики; результат живе
лише в пам'яті сторінки. Єдиний зовнішній запит — шахова бібліотека
[chess.js](https://github.com/jhlywa/chess.js) 0.10.3 (BSD-2-Clause) з CDN jsDelivr, із
фіксованою версією й перевіркою цілісності (SRI).
