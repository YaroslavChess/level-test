# Безкоштовна діагностика рівня

Тест для сайту шахової школи [yaroslavchess.com](https://yaroslavchess.com): 12 коротких
задач «знайди найкращий хід» на інтерактивній дошці, потім результат (один із п'яти рівнів:
Новачок, Початківець, Середній, Впевнений, Сильний) і кнопка запису на безкоштовний пробний
урок. Для українських батьків за кордоном (діти 6–14 років) і дорослих. Текст результату
написано без шахових термінів.

Увесь тест — **один файл `index.html`**. Збирати нічого не потрібно: відкрийте його в
браузері (потрібен інтернет для шахової бібліотеки).

## Як це працює

- Старт: «Дитина» / «Дорослий» і кнопка «Почати». Кнопка «Ще не граю» одразу дає «Новачок».
- Одна спроба на задачу, без підказок. Правильна відповідь — наступна задача складніша,
  помилка — простіша.
- Ходи — натисканням: спершу на фігуру, потім на клітинку.
- Результат: рівень, пояснення з двох речень і кнопка запису.

## Публікація

GitHub Pages: Settings → Pages → *Deploy from a branch* → `main`, папка `/ (root)`.
Адреса: `https://yaroslavchess.github.io/level-test/`. Сторінку можна вставити на сайт через
`<iframe>` або дати як посилання.

## Що можна налаштувати

Усе в блоці «НАЛАШТУВАННЯ» на початку скрипта в `index.html`:

- `BOOKING_URL` — куди веде кнопка запису (зараз `https://www.yaroslavchess.com/appointment`);
- `LEVELS` — назви рівнів і пороги (0 / 700 / 1000 / 1300 / 1650);
- `RESULT_TEXTS` — пояснення до рівнів (рівно два речення, без шахових термінів);
- `START_RATING`, `TOTAL_TASKS`, `STEPS` — стартова складність, кількість задач, крок складності.

Пороги й назви рівнів міняйте лише за згодою власника.

## Задачі

Задачі взято з відкритої бази [Lichess](https://database.lichess.org) (CC0) без змін і
лежать у масиві `PUZZLES` в `index.html`. **Вручну їх не вигадуємо й не правимо.** Оновити
набір можна скриптом `tools/pick_puzzles.py`:

1. Завантажте базу: <https://database.lichess.org/lichess_db_puzzle.csv.zst> (близько 300 МБ).
2. `pip install zstandard` (лише для `.zst`).
3. `python3 -I tools/pick_puzzles.py lichess_db_puzzle.csv.zst puzzles.js`
4. Замініть вміст між `PUZZLES:START` і `PUZZLES:END` в `index.html` на `puzzles.js`.

Після оновлення перевірте, що всі позиції коректні, а ходи легальні (скрипт — у `CLAUDE.md`).

## Приватність

Сторінка не збирає й не зберігає персональних даних: немає форм, cookie, `localStorage`,
аналітики. Результат існує лише в пам'яті сторінки. Єдиний зовнішній запит — завантаження
бібліотеки [chess.js](https://github.com/jhlywa/chess.js) 0.10.3 з CDN jsDelivr (із
перевіркою цілісності). Кнопка запису відкриває сторінку на сайті школи.
